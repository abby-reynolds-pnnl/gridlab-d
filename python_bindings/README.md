GridLAB-D Python bindings (nanobind).
Contains bindings for simple API wrappers

To test:
1. Create conda env locally.
2. Install gridlabd library from test.pypi.org:
    python -m pip install --index-url https://test.pypi.org/simple --extra-index-url https://pypi.org/simple gridlabd==0.0.1
3. Run the test.ipynb notebook.
